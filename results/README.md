# 实验数据说明

本目录记录四配置 × 三种子的 12 次训练，所有主表为固定第80轮模型。数据来自项目保存的训练历史与离线指标，汇总均值和样本标准差，不修改实验数值。

| 文件 | 内容 |
| --- | --- |
| final_metrics_by_seed.csv | 12次训练、5个数据集、5项指标，共300行逐种子数值 |
| summary.json | 各配置、数据集、指标的均值、样本标准差与逐种子原值 |
| run_protocol_and_selection.csv | 更新数、batch size、参数量、末轮/选优日志MAE及best轮次 |
| late_test_mae.csv | 第60–80轮的三种子Test MAE |
| run_records/ | 每次训练的配置、训练历史、选模历史和末轮指标记录 |
| source_manifest.json | 公开记录的来源与文件摘要，配置移除机器绝对路径 |

主表是离线PNG指标，选模对照是日志浮点指标，分别报告。best按UVT20K Test最低MAE选取，不是独立验证集选择。离线原始指标保留四位小数，均值额外位数用于汇总；样本标准差使用n-1分母，n=3。

公开训练配置保留超参数、初始化摘要、样本计数和模型结构，仅移除与复现无关的机器绝对路径；原文件摘要记录于来源清单。历史与指标的数值保持原样。

本目录不含图像数据集、全部预测图或大权重。真实预测示例为docs/figures/fig05_qualitative.png，对应种子42、固定第80轮；样本按候选MAE差筛选，完整规则见qualitative_selection.json。
